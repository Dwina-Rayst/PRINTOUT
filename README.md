# PRINTOUT

> 그저 버려진 공장일 뿐이라고 생각했다면 틀렸습니다. 이 타워는 기계를 '번식'시키는 곳입니다.

3인칭 3D 공포 타워 클라이밍 웹게임. Roblox 타워류 + Poppy Playtime 시리즈의 재미 요소를 결합했습니다.
Three.js(WebGL)로 동작하는 순수 웹 클라이언트 + Express/Turso 백엔드(회원 계정, 최고 층 기록) 구조입니다.

## 폴더 구조
```
printout-game/
├── index.html          # 진입점 (로그인→성별선택→컷씬→게임 UI)
├── css/style.css        # 다크/공포 톤 UI
├── js/
│   ├── config.js         # 밸런스/몬스터/보스/아이템 데이터
│   ├── auth.js            # 로그인/회원가입 (서버 연동 + 오프라인 폴백)
│   └── main.js             # Three.js 게임 본체 (컷씬, 전투, 층 생성, 보스)
└── server/               # 백엔드 (Express + Turso)
    ├── server.js
    ├── schema.sql
    ├── package.json
    └── .env.example
```

## 로컬 실행
프론트엔드는 정적 파일이므로 별도 빌드가 필요 없습니다.
```bash
# 저장소 루트에서
npx serve .
# 또는
python3 -m http.server 8080
```
브라우저에서 `http://localhost:8080` 접속 후 클릭 → 마우스 포인터 잠금(3인칭 시점 조작) → WASD 이동, 마우스로 시점 회전, 좌클릭 공격, `F` 상호작용(아이템 줍기), `I` 인벤토리/휴대폰.

> 백엔드가 실행 중이 아니면 로그인 화면에서 자동으로 **오프라인(로컬) 모드**로 전환되어 `localStorage`에 계정 정보를 저장합니다. 비밀번호는 평문이 아닌 SHA-256(salt+비밀번호) 해시로 저장되고, 저장 데이터 전체는 base64 인코딩 + 무결성 체크섬으로 감싸져 있어 devtools로 값을 손대면 자동으로 무효 처리됩니다. 다만 이는 "같은 컴퓨터의 다른 사용자가 아무 생각 없이 들여다보거나 고치는 것"을 막는 수준이며, 작정하고 파고드는 사람까지 막는 진짜 보안은 아닙니다 — 진짜 보안이 필요하면 Turso/서버 연동이 필요합니다. (참고: `crypto.subtle`은 HTTPS 또는 localhost에서만 동작합니다.)

## 백엔드(Turso + Render) 배포
1. **Turso 데이터베이스 생성**
   ```bash
   turso db create printout-db
   turso db show printout-db --url
   turso db tokens create printout-db
   ```
2. `server/.env.example` 을 `server/.env` 로 복사하고 위에서 발급받은 값을 채워 넣습니다.
3. **Render 배포**
   - Render 대시보드 → New → Web Service → 이 저장소 연결
   - Root Directory: `server`
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Environment Variables 에 `TURSO_DATABASE_URL`, `TURSO_AUTH_TOKEN` 추가
4. 배포된 URL(`https://your-app.onrender.com`)을 프론트엔드에 연결하려면 `index.html` 의 `</head>` 앞에 아래를 추가하거나 `js/auth.js` 상단의 `API_BASE` 기본값을 바꿔주세요.
   ```html
   <script>window.PRINTOUT_API_BASE = "https://your-app.onrender.com";</script>
   ```

## 프론트엔드(GitHub Pages) 배포
루트 폴더 전체(정적 파일)를 GitHub Pages, Render Static Site, Vercel, Netlify 등 아무 정적 호스팅에 올리면 됩니다. Three.js는 CDN(unpkg)에서 importmap으로 로드하므로 별도 빌드 과정이 필요 없습니다.

## 게임 시스템 요약
- **회원가입/로그인 → 성별 선택**(남/여 아바타 및 컷씬 반영) → **인트로 컷씬**(스킵 가능) → 게임 시작
- 시작 체력 80 / 최대 100 / 기본 공격력·방어력 0. 플레이어가 첫 걸음을 떼는 순간 **3D펜 지네 15마리**가 추격 시작
- 3D펜 지네: 체력 5 / 방어력 10 / 공격력 20, 닿으면 20 데미지 + **독 4×3초(중첩 가능)**
- 맵 곳곳의 고물더미 중 하나에 아이템이 숨겨져 있으며 `F`로 상호작용해 획득 (1층은 **무조건 단검** 고정, 이후 무기 28% / 방어구 32% / 음식 40% 확률)
- 단검(공격력 +20)이면 지네를 한 방에 처치 가능
- 계단에 접근하면 즉시 다음 층으로 이동, 계단 사용 시 체력 -3
- **2222층: 잉크 프린터**(중간 보스) — 이름과 1~50% 랜덤 수치가 적힌 종이를 발사, 맞으면 최대체력 비례 데미지
- **4444층: PRINTER**(최종 보스) — 사악한 대사 이후, 지금까지 등장한 모든 몬스터(잉크 프린터 포함, 스탯 4배)를 0.4~4초 간격 랜덤으로 소환
- 휴대폰 첫 메시지: 발신자 번호가 최종 보스 이름 `PRINTER`의 2진수(`01010000 01010010 01001001 01001110 01010100 01000101 01010010`)로 표시되며 드래그/복사 불가 (떡밥 요소)
- 층 구간별 추가 몬스터: 단선 스파이더(300F~), 브라운관 좀비(700F~), 냉각팬 유령(1100F~), 배터리 폭발체(1600F~), 회로 하운드(1900F~) — 상세 스탯은 `js/config.js` 참고

## 테스트/시연용 디버그 기능
4444층까지 실제로 걸어서 도달하려면 매우 오래 걸리므로, 게임 중 **`` ` `` (백틱) 키**를 누르면 원하는 층으로 즉시 이동할 수 있는 디버그 기능을 넣었습니다. 실제 정식 출시 시에는 `js/main.js` 최하단의 해당 블록을 제거하세요.

## 알려진 제한사항 (추후 개선 포인트)
- 현재 3D 모델은 모두 기하학적 프리미티브로 제작된 스타일라이즈 에셋입니다. 고품질 3D 모델(GLTF)로 교체하면 완성도가 크게 올라갑니다.
- 사운드/음악, 조명 베이킹, 인벤토리 내 아이템 개별 목록 UI 등은 후속 작업으로 남겨두었습니다.
- 4444개 층은 절차적으로 생성되며, 층별 완전히 수작업으로 디자인된 레이아웃은 아닙니다.
- 백엔드는 최소한의 인증만 제공합니다(세션/JWT 없음). 실서비스 전 보안 강화를 권장합니다.
